The APK is built from the public source at github.com/velkan14/nord-pass and signed with the same key for every release.

Updates

A sideloaded app does not update itself. Check this page for new versions, or add github.com/velkan14/nord-pass to Obtainium and select dev.damado.nordpass to be notified when a new release is published.

Privacy

Nord Pass has no backend. Your gym username and session cookie are encrypted and stored only on your device; the QR token is effectively a temporary gym key, so treat screenshots of it as sensitive.
